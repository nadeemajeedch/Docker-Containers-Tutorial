## You should already be able to

If Part 1 is done, you can:

- Explain images vs containers vs Hub
- Install and verify Docker
- `docker pull python:3.12`
- `docker run --rm python:3.12 python --version`
- `docker run -it python:3.12`
- Start, stop, exec, logs, inspect, cp, rm

Part 2 assumes those skills. It will not re-teach `docker ps`.
